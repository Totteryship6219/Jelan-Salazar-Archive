Chapter 5 – Digital Security and Ethics security.html

Assignment 6: Security, Ethics, and Password Protection

Objective: Demonstrate understanding of cybersecurity, password protection, phishing, malware, online privacy, and AI ethics, complete with a local browser-based password strength checker.

1. Strong Passwords & MFA

A strong password contains 12–16+ characters combining uppercase, lowercase, numbers, and symbols. Using unique passwords for each account prevents credential stuffing if one site is breached.

Defense: Password managers encrypt credentials, while Multifactor Authentication (MFA) requires a second verification factor (authenticator app or hardware key).

2. Phishing Attacks

Phishing uses deceptive emails, texts (smishing), or fake login pages impersonating banks or universities to trick users into revealing passwords or financial data.

Red Flags: Urgent threats ("Account suspended!"), mismatched sender domains (e.g., support@caldwell-verify.net), and generic greetings.

3. Malware Defense

Malicious software includes Viruses (self-replicating code), Ransomware (encrypts files for extortion), and Spyware (secretly tracks keystrokes and credentials).

Prevention: Install OS security updates promptly, run real-time endpoint antivirus, avoid pirated downloads, and maintain offline backups.

4. Online Privacy

Protecting Personally Identifiable Information (PII) prevents identity theft and invasive data brokerage tracking across websites and social networks.

Best Practices: Audit social media privacy settings, block third-party tracking cookies, verify HTTPS encryption, and never overshare location data.

5. AI Ethics & Responsible Use

Artificial intelligence raises critical ethical concerns around algorithmic bias, training data privacy, deepfake misinformation, and copyright/intellectual property rights.

Responsibility: Users must fact-check AI-generated outputs against primary sources, never input confidential accounting or client data into public AI models, and cite original creators.

Chapter 3 – Evaluating Hardware hardware.html

Assignment 4: Hardware Evaluation Page

Objective: Evaluate common computer hardware components (CPU, RAM, SSD, GPU) with visual gallery cards and an architectural comparison table.

CPU (Processor)

Executes program instructions, arithmetic logic, and control operations measured in GHz across multiple cores.

RAM (System Memory)

High-speed volatile memory that temporarily stores active OS processes, open browser tabs, and large spreadsheets.

SSD (Solid State Drive)

Non-volatile flash storage with no moving parts, delivering rapid boot times and reliable persistent file storage.

GPU (Graphics Unit)

Parallel processor engineered to accelerate 2D/3D rendering, multi-monitor displays, video encoding, and AI workloads.

Component Description Importance & Evaluation Criteria
CPU Central Processing Unit — the 'brain' of the computer containing the Control Unit and Arithmetic Logic Unit (ALU). Determines overall calculation speed and responsiveness; evaluated by core count, clock speed (GHz), and cache size.
RAM Random Access Memory — fast, short-term volatile workspace that clears when power is turned off. Prevents system slowdowns during heavy multitasking (16GB–32GB DDR5 recommended for modern business workflows).
SSD Solid State Drive — non-volatile NAND flash storage device that retains data permanently without power. Dramatically faster and more shock-resistant than mechanical HDDs; cuts OS boot and application load times to seconds.
GPU Graphics Processing Unit — specialized processor with thousands of cores for parallel visual and matrix math. Essential for high-resolution displays, video production, 3D visualization, and local machine learning acceleration.

A global packet-switched network connecting millions of devices using TCP/IP protocols, routers, fiber-optic backbones, and DNS servers that translate domain names into IP addresses.

2. Internet Service Providers (ISPs)

Companies (such as Verizon Fios, Comcast Xfinity, and AT&T) that provide residential and business subscribers with high-speed broadband, fiber, or wireless access to the Internet.

3. Web Browsers

Client software applications (Google Chrome, Mozilla Firefox, Apple Safari, Microsoft Edge) that request webpages via HTTP/HTTPS and render HTML, CSS, and JavaScript code into interactive pages.

4. Search Engines

Information retrieval systems (Google, Bing, DuckDuckGo) that use automated web crawlers to index billions of pages and rank relevant results for user keyword queries.

Chapter 1 – Being a Digital Citizen digital-citizen.html

Assignment 2: Digital Citizen Reflection Page

Objective: Discuss digital citizenship, ethical student behavior online, digital footprints, and why responsible digital engagement matters.

1. What is a Digital Citizen?

A digital citizen is an individual who possesses the technical literacy, ethical awareness, and critical thinking skills required to engage safely, respectfully, and responsibly in digital environments, online communities, and academic networks.

2. How Should Students Behave Online?

Students should practice constructive netiquette, uphold strict academic integrity (properly citing sources and avoiding plagiarism), respect diverse viewpoints, protect peer privacy, and never engage in cyberbullying or harassment.

3. What is a Digital Footprint?

A digital footprint is the permanent trail of data left behind when using the internet—including active footprints (social media posts, public comments, uploaded portfolios) and passive footprints (IP logs, browsing history, and cookies).

4. Why is Digital Citizenship Important?

Responsible digital citizenship safeguards personal security, builds a trustworthy professional reputation for future employers (especially in fields like accounting and municipal finance), and fosters inclusive, trustworthy digital spaces.
